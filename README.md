# 🌌 Algorithmic Art & Chaos Lab

Laboratório visual interativo para exploração de **sistemas dinâmicos complexos, campos de fluxo vetorial, atratores estranhos caóticos, autômatos celulares e geometria filotática áurea** em HTML5 Canvas a 60 FPS.

## ✨ Motores Matemáticos Inclusos

1. **🌊 Campo de Fluxo Trigonométrico (*Flow Field*)**:
   - Milhares de partículas autônomas guiadas por campos vetoriais contínuos com formação de vórtices interativos ao mover o mouse.
2. **🦋 Atrator Estranho de Clifford (*Chaos Attractor*)**:
   - Renderização em espaço de fase do sistema não-linear acoplado:
     `x_{n+1} = sin(a·y_n) + c·cos(a·x_n)` e `y_{n+1} = sin(b·x_n) + d·cos(b·y_n)`.
3. **🧬 Autômato Celular de Conway (*Game of Life B3/S23*)**:
   - Simulação emergente com rastro luminescente (*afterglow*) e pincel ao vivo para desenhar novas colônias com o mouse.
4. **🌻 Filotaxia Áurea (*Golden Ratio Spiral*)**:
   - Disposição espiral logarítmica governada pelo Ângulo Áureo (`137.50776°`), simulando padrões biológicos e galácticos.

## 🎨 Recursos para Criadores

- **4 Paletas Curadas**: *Cyberpunk*, *Aurora Boreal*, *Chama Solar* e *Monocromático*.
- **Mutação Matemática (`[R]`)**: Gera novas sementes estocásticas instantaneamente.
- **Exportação PNG em Alta Resolução**: Salve suas criações generativas com um clique.

## 🚀 Como Executar

Abra `index.html` diretamente no navegador ou acesse via GitHub Pages.
